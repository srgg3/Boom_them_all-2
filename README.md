# Boom them all — 2 💣

Игра на Pygame, в которой нужно обезвреживать бомбы, кликая по ним мышкой. При клике бомба взрывается — появляется анимация взрыва.

## Демонстрация

(Здесь можно добавить скриншот или GIF-анимацию игры)

## Особенности

- 10 бомб случайно размещены на игровом поле без пересечений.
- При клике на бомбу она заменяется изображением взрыва.
- Простая, но затягивающая механика «найди и взорви».

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/srgg3/boom-them-all-2.git
   cd boom-them-all-2
   ```

2. **Установите Pygame:**
   ```bash
   pip install pygame
   ```

3. **Подготовьте изображения:**  
   Поместите в папку `data/` два файла:
   - `bomb2.png` — изображение активной бомбы.
   - `boom.png` — изображение взрыва (анимация).

4. **Запустите игру:**
   ```bash
   python main.py
   ```

## Как играть

- На экране появляются бомбы.
- Кликайте по ним левой кнопкой мыши — бомба взорвётся.
- Взорванные бомбы больше нельзя активировать.

## Управление

| Действие | Клавиша |
|----------|---------|
| Взорвать бомбу | Левый клик мыши по бомбе |
| Выйти из игры | Закрыть окно |
